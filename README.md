# toolkit

Мой первый проект на Python — CLI-программа с двумя модулями: калькулятор математических выражений и конвертер единиц измерения.

## Зависимости

- [`typer`](https://typer.tiangolo.com/) — CLI-интерфейс
- [`uv`](https://github.com/astral-sh/uv) — управление зависимостями и установка в editable-режиме

## Установка

git clone https://github.com/Rushan4ik/Lab01.git
cd Lab01
uv pip install -e .


## Использование

```bash
python -m toolkit calc "Выражение"
python -m toolkit convert Значение Единица1 Единица2
python -m toolkit --help
```

> **Совет:** если выражение начинается с минуса, передавайте его через `--`:
> ```bash
> python -m toolkit calc -- "---5+10"
> ```

## Примеры

python -m toolkit calc "3--2*2 + 3//2 - 5*+1"   # → 3.0
python -m toolkit calc "6*-7 + 100//3"            # → 91.0
python -m toolkit convert 36.6 c f                # → 97.88
python -m toolkit convert 1 km m                  # → 1000.0

## Калькулятор

Поддерживаемые операторы:

| Оператор | Описание              |
|----------|-----------------------|
| `+`, `-` | Сложение, вычитание   |
| `*`      | Умножение             |
| `/`      | Деление               |
| `//`     | Целочисленное деление |
| `%`      | Остаток от деления    |

**Особенности:**
- Унарные `+` и `-` (в том числе после `*`, `/`, `//`, `%`)
- Вычисления через `decimal.Decimal` с округлением `ROUND_HALF_UP`
- Результат всегда `float`

## Конвертер

Поддерживаемые единицы измерения:

| Категория    | Единицы              |
|--------------|----------------------|
| **Длина**    | `mm`, `cm`, `m`, `km`|
| **Масса**    | `g`, `kg`            |
| **Температура** | `c`, `f`, `k`     |

## Обработка ощибок

Программа выбрасывает понятные сообщения при:
- пустом выражении
- недопустимых символах
- двух операторах подряд(кроме унарных)
- делении на ноль
- некорректном числе
